# pc-remote-bot

[English](README.md) · **Русский**

Telegram-бот для удалённого включения и управления Windows-компьютером: Wake-on-LAN, статус,
скриншоты, процессы, команды PowerShell, блокировка, сон, перезагрузка и выключение.

## Возможности

| Команда | Кнопка | Что делает |
| --- | --- | --- |
| `/wake` | ⚡ Включить ПК | Отправляет Wake-on-LAN пакет и сообщает, когда ПК включился |
| `/ping` | 📡 Проверить ПК | Проверяет, отвечает ли ПК на ping |
| `/status` | 📊 Статус | CPU, память, диски, время работы |
| `/screen` | 🖥 Скриншот | Скриншот всех мониторов |
| `/ps` | 📋 Процессы | Топ процессов по памяти |
| `/kill chrome` или `/kill 1234` | ❌ Завершить процесс | Завершает процесс по имени или PID |
| `/cmd Get-Date` | ⌨️ PowerShell | Выполняет команду PowerShell (таймаут 60 с) |
| `/lock` | 🔒 Заблокировать | Блокирует экран |
| `/sleep` | 😴 Сон | Переводит ПК в сон |
| `/reboot` | 🔄 Перезагрузка | Перезагрузка через 30 с (с подтверждением) |
| `/shutdown` | ⏻ Выключить | Выключение через 30 с (с подтверждением) |
| `/cancel` | ↩️ Отменить выключение | Отменяет запланированное выключение или перезагрузку |

Ботом могут пользоваться только пользователи из `ALLOWED_USER_IDS`. Остальным он отвечает
«Нет доступа» и показывает их Telegram ID.

## Как это устроено

Один и тот же код работает в двух ролях, роль задаётся в `.env`:

- **На самом ПК** (`ENABLE_CONTROL=true`): всё, кроме включения.
- **На всегда включённом устройстве в той же сети** (второй ПК, ноутбук, Raspberry Pi) с
  заданным `WOL_MAC`: `/wake` и `/ping`. Выключенный компьютер не может включить сам себя,
  поэтому эта часть должна работать на другом устройстве.

Обе роли можно запускать с одним токеном, только если они никогда не работают одновременно.
Иначе создайте в @BotFather двух ботов.

## Что нужно

- Windows 10/11 (команды управления используют средства Windows)
- [uv](https://docs.astral.sh/uv/) (сам установит Python 3.12+)
- Токен бота от [@BotFather](https://t.me/BotFather)

## Установка

1. Склонируйте репозиторий и установите зависимости:

   ```powershell
   git clone https://github.com/namadeku/pc-remote-bot.git
   cd pc-remote-bot
   uv sync
   ```

2. Создайте файл настроек:

   ```powershell
   Copy-Item env.example .env
   ```

   Откройте `.env` и впишите `BOT_TOKEN`.

3. Узнайте свой Telegram ID: запустите бота (`uv run pc-remote-bot`) и отправьте ему
   `/start`, он ответит вашим ID. Впишите его в `ALLOWED_USER_IDS` и перезапустите бота.

4. Снова отправьте `/start`, и появится клавиатура со всеми действиями.

### Настройки (`.env`)

| Переменная | Описание |
| --- | --- |
| `BOT_TOKEN` | Токен от @BotFather (обязательно) |
| `ALLOWED_USER_IDS` | Telegram ID пользователей с доступом, через запятую |
| `ENABLE_CONTROL` | `true` на самом ПК: включает статус, скриншоты, команды питания |
| `WOL_MAC` | MAC-адрес **проводного** адаптера ПК; включает `/wake` |
| `WOL_HOST` | Широковещательный адрес сети (например, `192.168.1.255`) или внешний адрес/DDNS роутера, если он пробрасывает UDP |
| `WOL_PORT` | Порт Wake-on-LAN, обычно `9` |
| `PC_HOST` | Локальный IP ПК для `/ping` и уведомления «ПК включился» |
| `PROXY_URL` | Необязательный прокси для Telegram, например `socks5://127.0.0.1:10808` |

### Чек-лист Wake-on-LAN

- В BIOS/UEFI включите **Wake on LAN** / **Power On by PCI-E**.
- В диспетчере устройств: сетевой адаптер → *Управление электропитанием* → разрешите будить
  компьютер; на вкладке *Дополнительно* включите *Wake on Magic Packet*.
- Отключите **быстрый запуск** (Панель управления → Электропитание → *Действия кнопок питания*).
- Подключите ПК кабелем: большинство Wi-Fi-адаптеров не умеют будить компьютер.
- MAC-адрес можно узнать командой `Get-NetAdapter | Select Name, MacAddress`.

## Автозапуск

Бот может работать без окна консоли через `pythonw`. Логи тогда пишутся в `bot.log` в
папке проекта.

1. Нажмите `Win+R`, введите `shell:startup` и нажмите Enter.
2. Создайте там ярлык:
   - **Объект:** `C:\путь\к\pc-remote-bot\.venv\Scripts\pythonw.exe -m pc_remote_bot`
   - **Рабочая папка:** `C:\путь\к\pc-remote-bot`

Бот стартует после входа в систему и сам ждёт, пока появится сеть.

## Безопасность

`/cmd` даёт полный доступ к PowerShell на компьютере. Держите `ALLOWED_USER_IDS` коротким,
никому не давайте токен бота и не коммитьте `.env` (он уже в `.gitignore`).
